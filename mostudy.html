GAS 데이터베이스 설정

기본적으로 브라우저(LocalStorage)에 저장되며, 담임교사 Google Apps Script 웹앱 URL을 넣으면 구글 시트에 자동 통합됩니다.

📌 GAS 구축 3단계:

  1. 구글 시트 생성 ➔ [확장 프로그램] ➔ [Apps Script] 클릭
  2. 아래 코드를 붙여넣고 저장 후 [배포] ➔ [새 배포] 클릭
  3. 액세스 권한: "모든 사용자(Anyone)" 설정 후 Web App URL을 여기에 붙여넣기
